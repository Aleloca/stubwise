## What is Stubwise

Stubwise is an issue tracker you install on your own server. It has three parts
that work together:

- an **SDK** that captures errors (and feedback) from your application and sends
  them to the instance;
- a complete **issue tracker** (projects, tickets, Kanban board, comments) to
  manage them by hand;
- an **optional AI pipeline** that tries to resolve tickets automatically,
  opening a pull request that a human reviews before merging.

The AI is **optional**: without authenticating the Claude CLI, Stubwise stays a
perfectly functional self-hostable issue tracker.

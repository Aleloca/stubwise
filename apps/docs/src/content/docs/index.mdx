## Cos'è Stubwise

Stubwise è un issue tracker che si installa su un server tuo. Ha tre parti che
lavorano insieme:

- un **SDK** che catturi gli errori (e i feedback) dalla tua applicazione e li
  invia all'istanza;
- un **issue tracker** completo (progetti, ticket, board Kanban, commenti) per
  gestirli a mano;
- una **pipeline AI opzionale** che prova a risolvere i ticket automaticamente,
  aprendo una pull request che un umano rivede prima di mergiare.

L'AI è **opzionale**: senza autenticare il CLI di Claude, Stubwise resta un
issue tracker self-hostabile perfettamente funzionante.

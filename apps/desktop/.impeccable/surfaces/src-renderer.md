## Direction contract

THESIS: every citable thing (task, docs page, drive file, automation, incoming event) is a catalog entry with a citable code; the code anchors the row, the name is always readable beside it. Refuses the boxed-card dashboard with shadows and decorative gradients.

OWN-WORLD: flat surfaces, thin hairline rules instead of boxes and shadows, calm space. Spaced uppercase labels only for group headings. Few solid colors that encode meaning: department color is the main one (thin strip left of each row, with legend); status red/amber/green only where it carries meaning; brand amber stays on the logo. Dark is the cover (opaque black, white ink), light is its negative (paper, black ink). One precise grotesque with tabular figures, never monospace except the logo.

STORY: the user sees what is theirs and what waits on them, trusts that every item has a stable code they can paste anywhere, and acts on the next task with one key (J/K).

FIRST VIEWPORT: 1440x900. Sidebar 236px (logo S_, search, nav, pinned projects with code and department strip), main list grouped Overdue/Today/This week with 44px rows (code, title, project, due, status, avatar) under a 28px title, right panel 328px "Waiting on you" with the primary action chips inline. Reference sketch: .impeccable/mocks/decision/challenger-catalog.html.

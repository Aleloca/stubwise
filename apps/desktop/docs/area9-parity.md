# Area 9a — parità con il web (30 ott 2026)

Una riga per ogni voce delle sezioni A (Personale → Preferenze) e B (Persone e
accessi) di `area9-inventory.md`, poi le voci **fuori** col motivo e le voci C,
D, E rimandate a 9b e 9c. Percorsi relativi a `src/renderer/`. Stessa regola
delle aree precedenti: il test citato (titolo fra virgolette, anche solo
l'inizio) esercita davvero quella voce; dove non c'è, la colonna lo dice.

In sintesi: l'ingresso è `pages/entry/` (login, invito, reset, primo avvio);
le Preferenze sono `#/preferences/<sezione>`; Amministrazione è `#/admin/*`;
Members è Progetto → Settings → Members (`#/p/<CODE>/settings/members`).
«REAUTH» = la voce chiede la riconferma (`layout/ReauthDialog.tsx`,
`data/auth/reauth.ts`).

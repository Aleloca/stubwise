Area 8, F3 — Support dal server MCP (modalità collaboratore). `create_backlog_item` accetta la conversazione con l'utente (`conversation`, facoltativa): viene allegata alla richiesta, il team la legge in Support e può rispondere. `my_requests` mostra le risposte del team sotto la richiesta. Le istruzioni del server dicono di allegare la conversazione e dove trovare le risposte. Un server più vecchio ignora il campo.
